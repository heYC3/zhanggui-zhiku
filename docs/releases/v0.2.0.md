# 掌柜智库 v0.2.0

本版本将商品资料问答、Shopify 开发店受控 DRAFT 写入与 PythonAnywhere 单账号在线测试串联到同一项目展示中。

## 主要变化

- 私有手册验收：公开评测方法、脱敏汇总与验收摘要；原始手册、题目、答案和运行留在本机。24 道首次新题严格通过 23/24、指定文字要点 47/47、显式选图 4/5，同一开发者借助 Codex 出题和复核，不是独立盲评。
- Shopify 开发店：持久化写入意图、人工确认、幂等与并发控制、结果不明时核对、独立远端读回与重启恢复；只创建 DRAFT。
- 在线测试：PythonAnywhere 单账号 Listing、任务用量看板、单实例运行约束和运行目录备份恢复；入口为 <https://zhanggui.pythonanywhere.com/>，工作台需要授权账号，仅本人测试。
- 展示整理：统一问答品牌及公开 X1 示例，修正终态进度并重新截图，说明第二步 61 项与当前 72 项测试的历史区别；公开 `.gitignore` 使用 `private_materials/`，现有本机历史材料单独排除；公开草稿图裁去登录和输入区域。

## 验证与边界

本版本的工程回归包括 Listing 72 项、RAG 合成测试 39 项、公开冻结基线一致性及容器卷两次启动后的恢复检查，结果见 [GitHub Actions](https://github.com/heYC3/zhanggui-zhiku/actions/workflows/listing-ci.yml)。2026-11-08 的只读查询确认自编 X1 与 P20 商品仍为 DRAFT；本次展示整理未新增商品，也未重跑私有冻结题。

云端只包含 Listing 和公开自编商品，手册导入与 RAG 问答仍在本机运行。最近一次公开导入在 Milvus 连接阶段失败，未成功入库；公开问答截图使用离线证据与真实模型。真实店故障注入、多店商家授权、MinIO 后端与生产高可用尚未完成验收。
