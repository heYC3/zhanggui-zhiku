# 评测与验证

[返回首页](../README.md) · [架构与实现](architecture.md) · [运行指南](running.md)

本页汇总截至 2026-11-08 的结果，区分公开合成测集、私有手册验收和工程测试。它们检验不同能力，不合成总体准确率。

## 真实手册：一次性新题验收

验证语料为5本手册、298条正文。54题由旧30题开发回归与新24题组成；新题覆盖新增2本手册，逐题对原PDF核对事实、页码、支持切片与必要图片，出题和核对期间不调用被测问答。

修复开发问题后，固定系统、模型配置、来源、题目、答案与评分，生成SHA256清单。新题完整运行一次，之后只复核保存结果，不根据新题调系统、不挑题或续跑。旧题因已用于开发，只作回归。

| 指标 | 旧30题开发回归 | 新24题首次验收 |
| --- | --- | --- |
| 有明确正文事实的问答 | 30 | 20 |
| 资料不足 / 澄清题 | 未独立分组 | 2 / 2 |
| 运行完成 / 阶段错误 | 30/30；0 | 24/24；0 |
| 检索 hit@1 | 26/30 | 19/20 |
| 检索 hit@3 | 30/30 | 20/20 |
| 前三条指定证据要点覆盖 | 58/58 | 45/47 |
| 实际生成上下文证据覆盖 | 58/58 | 47/47 |
| 答案指定文字要点覆盖 | 58/58 | 47/47 |
| 产品路由正确 | 不与新题合算 | 24/24 |
| 资料不足与澄清行为 | 不与新题合算 | 4/4 |
| 指定图片在返回候选列表中 | 图片专项 | 5/5 |
| 回答显式选图正确 | 未单列 | 4/5 |
| 严格整题通过 | 不与新题合算 | **23/24** |

`hit@3` 只要求前三条与相关证据集合有交集。证据覆盖逐点核对支持切片是否进入前三或实际上下文；文字覆盖逐点阅读最终答案。严格整题要求主体、所需要点、行为和必要图片均通过，且没有已识别的矛盾或无依据声明。

首次验收仍发现1题显式错图；另一道跨型号题有2个指定证据要点在前三之外，但已进入上下文且最终文字正确。候选图包含正确图不代表回答选图正确。具体题目、原图和失败归因只留本机，不披露私有验收内容。

### 验证边界

- 样本仅5本、首次验收仅24题，不能推出大规模泛化或线上业务收益。
- 同一开发者借助Codex实现、出题和复核，不是独立人工盲评；47/47只是指定事实覆盖，不是所有生成语句的准确率。
- 265条旧正文迁移时仅替换图片URL，逐字检查其余内容并复用原向量；封面补充与新手册共33条重新编码。新旧语料不同，不能将数字变化当成严格同语料的纯检索增益。
- 图片专项：413张去重图片HTTP状态和MIME通过；单张真实视觉模型导入与真实浏览器流式显示通过。同步/轮询为保存旧题结果的ASGI契约验证；页面进度提示存在滞后，MinIO后端未验收。
- 原PDF有而切片没有的CS407型号已通过封面补充恢复；其他编码异常不视为全部解决。
- 24道新题本次运行后即已暴露，未来只能作为回归资料。后续修复必须另立系统与验收版本。

### 结果来源

完整手册、题目、答案、图片、向量库及原始响应未纳入仓库。公开方法见 [手册评测协议](../knowledge_base/docs/manual_evaluation_protocol.md)，通用评分实现见 [evaluation.py](../knowledge_base/app/evidence/evaluation.py)，其测试使用合成正文。

## Listing：公开合成基线

数据为3个自编商品和演示平台规则，100题拆为开发62题、冻结38题。完成率只取冻结集的7道草稿题和9道流程题；检索另有22题。默认不调用模型，稠密路径使用离线字块替身。

| 配置 | 闭环成功 / 总数 | 检索 hit@3 |
| --- | --- | --- |
| 关键词基线，无确认门和规则校验 | 11/16 | 14/22 |
| 当前离线流程：RRF + 模板HyDE、确认门与校验 | 16/16 | 22/22 |

成功需型号正确、证据命中、草稿至少覆盖1个指定要点且无禁语，流程题还需确认路径正确。这是多个组件共同变化的小集合对照，不能将收益全部归于RRF或HyDE，也不等同真实模型或店铺效果。

- [冻结基线与逐题结果](../knowledge_base/listing_data/reports/baseline.md)
- [留出商品案例的分项结果](../knowledge_base/listing_data/reports/ablation.md)
- [真实模型与原句模板对照](../knowledge_base/listing_data/reports/llm_compare.md)：与离线基线分开，缺单价时费用未知。

公开题可用于复现回归，但题目已经公开，不能再称新的独立盲测。
